# Moonscars Android controls overhaul

This repository is used to research a configurable, accessible, high-quality touchscreen controller for an Android Moonscars port.

Goals: multi-touch virtual stick; full set of gameplay/menu inputs; editable layout, opacity, size, sensitivity and mappings; preserve performance and existing saves.

**Do not commit game APKs, copyrighted game assets, keystores or personal files to this public repository.** Inspection scripts should collect technical metadata only. Any reconstructed APK must be tested locally for compatibility and signing before installing over an existing build.
